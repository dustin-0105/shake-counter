# shake counter

100초 동안 흔든 횟수를 세는 한 페이지짜리 웹앱.

- `index.html` 하나가 전부. 외부 라이브러리·CDN 참조 없음.
- HTTPS 로 서빙해야 iOS 에서 모션 센서를 쓸 수 있다.

## URL 파라미터

| 파라미터 | 기본값 | 설명 |
|---|---|---|
| `s` | 100 | 측정 시간(초). 최소 5 |
| `t` | 55 | 흔들기 판정 민감도. 낮을수록 민감 |
| `g` | 110 | 같은 흔들기 중복 방지 간격(ms) |
| `mode` | — | `tap` 이면 화면 두드리기로 고정 |
